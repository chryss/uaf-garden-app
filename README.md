# UAF Community Garden App

Vue 3 + Vuetify + Firebase app for public plot registration and admin management.

## Quick start

```bash
npm install
npm run dev
```

Production build preview:

```bash
npm run build
npm run preview
```

## Routes

- Public: `/`, `/plot-registration`, `/returning-gardener`
- Admin: `/admin/login`, `/admin`
